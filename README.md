# tw-tax-planner-realprice

「台灣稅務專家」App 用的實價登錄住宅交易索引，整理自內政部不動產成交案件實際資訊開放資料（政府資料開放授權條款）。
依縣市代碼／行政區分檔，每筆保留地址、交易年月、總價、單價、建物與土地面積、屋齡、建材、樓層與地號持分，供 App 估算不動產價值。
`landvalue/` 是各縣市公告土地現值年度開放資料整理成的索引（縣市代碼／地段代碼.json：地號 → 元／㎡），每年 1 月更新。
`community/` 是社區名稱索引（縣市代碼.json：社區或建案名稱、行政區、地址、地段地號與比對可信度），整理自實價登錄預售屋建案名稱與各縣市公寓大廈管理組織報備名冊，地段地號由門牌對實價登錄成交紀錄比對而得，可能有誤。
資料僅供參考，不構成估價意見。
